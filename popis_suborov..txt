Popis súborov projektu QGen (Mlynček A) – stav po kroku 17 (služba v Dockeri).
Pôvodná Streamlit verzia (Hlavna_cast/) už nie je súčasťou repozitára; jej moduly sú
presunuté do qgen/. Prehľad služby a návody: README.md, docs/deployment.md, docs/integration.md.


Koreň projektu

.env.example
- Vzor konfigurácie so všetkými premennými a komentármi. Skopíruje sa do .env (nie je v gite).

Dockerfile
- Obraz služby (api, worker, webhook-worker). ARG INSTALL_OCR (predvolene true): torch pre CPU,
  EasyOCR a jeho modely stiahnuté pri builde. Beží pod používateľom bez root práv, HEALTHCHECK.

Dockerfile.mock
- Malý obraz mock API pre vývoj integrácie v Laraveli (bez pipeline a LLM).

.dockerignore
- Whitelist: do buildu ide iba qgen/, service/ a requirements (žiadne tajomstvá ani nahrávky).

docker-compose.yml
- Produkčné nasadenie: api, worker, webhook-worker, redis, volumes, sieť qgen a externá sieť ECEH,
  healthchecky, voliteľný profil local-llm (vLLM).

docker-compose.remote.yml
- Variant, keď ECEH beží na inom serveri: zverejnený port API pre server ECEH.

docker-compose.dev.yml
- Lokálny vývoj nad produkčným súborom: zverejnený port, QGEN_ENV=development, host.docker.internal.

docker-compose.replay.yml
- Vývoj bez nákladov: LLM a embeddingy z nahrávky baseline_v5/ (smoke test, resilience check).

docker-compose.mock.yml
- Mock API pre Laravel.

requirements-mock.txt, requirements-service.txt, requirements-ocr.txt, requirements.txt
- Závislosti s pevnými verziami: mock API; služba bez OCR; OCR (torch, EasyOCR, opencv headless);
  lokálny vývoj (všetko + pytest, fakeredis).

pytest.ini
- Nastavenie testov.

CLAUDE.md
- Pravidlá a rozhodnutia prerábky (zdroj rozhodnutí nad rámec špecifikácie).

README.md
- Čo služba robí, rýchly štart, režimy rozdelenia do hodín, príklady volaní, webhooky, chyby,
  replay, smoke test, overenie odolnosti, nahrávky, vývoj a testy.

baseline*/metrics.json
- Metriky nahrávok na referenčnom dokumente eko.pdf (prehľad v README, „Nahrávky“). Samotné
  nahrávky (llm_calls.jsonl a výstupy) obsahujú text dokumentu a sú iba lokálne.


qgen/ – jadro (pipeline bez webu)

qgen/config.py
- Všetky premenné prostredia (pydantic-settings). Jediné miesto, ktoré číta prostredie.

qgen/cli.py
- Spustenie pipeline z príkazového riadka; výsledky a reporty do priečinka, voliteľne units.

qgen/pipeline.py
- Celá pipeline po extrakcii: tematické celky a otázky.

qgen/progress.py
- Hlásenie priebehu progress_callback(stage, done, total).

qgen/context_builder.py
- Mapa strán dokumentu, čísla strán z citovaných zdrojov, kontext pre celok alebo otázku.

qgen/contract/
- Dátový kontrakt (Pydantic): options.py (vstupné nastavenia vrátane split), units.py (výstupný
  formát pre ECEH), report.py, jobs.py (stav úlohy, webhook, chyby), schemas.py (JSON schémy).

qgen/extraction/
- text_extraction.py: text z PDF (pypdf), voliteľné OCR obrázkov (pymupdf, EasyOCR).
- document_language.py: jazyk dokumentu (sk / en) cez LLM, záloha podľa textu.

qgen/llm/
- base.py (rozhranie LLM a embeddingov), factory.py (výber poskytovateľa, kontrola konfigurácie),
  retry.py (opakovania, čakanie pri 429, JSON), parallel.py (súbežné batche), json_load.py
  (bezpečné načítanie JSON), errors.py.
- adapters/: gemini.py, openai_compatible.py (OpenAI, Mistral, vLLM, Ollama …), anthropic.py,
  replay.py (odpovede z nahrávky, iba vývoj). Iba tu sa importujú knižnice výrobcov LLM.

qgen/lo/ – tematické celky (v pôvodnom kóde learning objects)
- generation.py (generovanie z textu po batchoch strán), clustering.py (embeddingy, zhlukovanie
  podobných celkov), prerequisites.py (prerekvizity), validation.py, faithfulness.py (vernosť
  voči textu), relevance_to_segment.py, topic_coverage.py (témy dokumentu a ich pokrytie),
  pipeline.py (celý postup a filter).

qgen/questions/ – otázky choice / open / no_answer
- prompts.py (prompty), pipeline.py (generovanie, doplňujúce kolá, pokrytie celkov, hodnotenie,
  filter), types.py (typy a ich pravidlá), validation.py, faithfulness.py, answerability.py,
  relevance_to_lo.py, dedup.py (duplicitné otázky), hints.py (nápoveda so zdrojom – dokument a strany).

qgen/split/ – rozdelenie do hodín (čisté funkcie bez LLM)
- sections.py (vstup), order.py (poradie podľa prerekvizít), topics.py (témy a ich úseky),
  syllabus.py (plán sylabu), lessons.py (režimy single, lessons, topics, syllabus, varovania).

qgen/output/ – výstupný krok
- split.py (krok split vrátane volaní LLM: témy, plán sylabu, názvy hodín), prompts.py,
  units.py (formát units), limits.py (dĺžkové limity ECEH, skrátenie cez LLM), sanitize.py
  (čistenie HTML nápovedí, nh3), report.py, check.py (kontrola modelom a JSON schémou).


service/ – HTTP služba

service/main.py
- FastAPI aplikácia (uvicorn service.main:app), OpenAPI dokumentácia na /docs.

service/settings.py
- Nastavenia služby (qgen.config + backend mock/real).

service/startup.py
- Bezpečnostná kontrola pri štarte: v produkcii odmietne štart bez QGEN_API_KEYS alebo bez
  QGEN_WEBHOOK_SECRET pri zapnutých webhookoch.

service/healthcheck.py
- Healthcheck kontajnerov (api, worker, webhook-worker).

service/routes/
- jobs.py (endpointy úloh), health.py (/health, /v1/info, schémy), deps.py (API kľúč, závislosti).

service/intake.py
- Kontrola vstupu POST /v1/jobs: options, PDF, počet strán, OCR, sylabus.

service/errors.py
- Jednotný formát chýb API.

service/backend.py, service/real_backend.py
- Rozhranie a skutočná implementácia úloh (job.json, fronta, external_ref v Redise).

service/jobs/
- models.py (obsah job.json), store.py (úlohy ako priečinky, atomický zápis), rq_queue.py a
  queue.py (fronta RQ), runner.py (jeden beh úlohy vo workeri), tasks.py (úlohy RQ a údržba),
  recovery.py (obnova nedokončených úloh), cleanup.py (mazanie PDF a výsledkov po TTL),
  refs.py (rezervácie external_ref), redis_lock.py, events.py (udalosti pre webhooky),
  convert.py (job.json → odpovede API).

service/webhooks/
- delivery.py (telo, hlavičky, pokus, plán opakovaní), signing.py (podpis HMAC-SHA256),
  hosts.py (povolení hostitelia), rq_delivery.py (doručovanie cez frontu qgen-webhooks),
  asyncio_dispatcher.py (iba mock).

service/worker.py, service/webhook_worker.py
- Vstupné body kontajnerov worker a webhook-worker.

service/mock/
- Mock backend (simulované úlohy, pevný výsledok z fixtures/).


Ostatné

schemas/
- JSON schémy units (lesson.schema.json), reportu a options (generované z Pydantic modelov).

tools/
- baseline.py (nahrávka a metriky), recording_client.py, smoke_test.py (smoke test Dockeru),
  resilience_check.py (odolnosť v kontajneroch), smoke_llm.py (jedno skutočné volanie LLM),
  webhook_receiver.py (lokálny prijímač webhookov), export_schemas.py, dedup_report.py.

tests/
- Unit, kontraktové, replay a integračné testy (pytest). Nikdy nevolajú skutočné LLM.

docs/
- Špecifikácia (PDF), deployment.md (nasadenie), integration.md (integrácia do Laravelu).
